## 数据口径

每次运行单独保存输入、模型与工具事件、用量、进度、回执、受控工作区、实际运行模块和当次事件记录器。预跑、失败和中止均在清单里。缺少完成记录时保留空值，核对时结合进度和产物判断。每条材料同时带原始摘要和公开数据摘要。真实网页实验另保存短摘录、取得记录和来源摘要。

公开版本将本机工作区和用户目录换成占位符，对启动凭据做脱敏。私人运行时会话存储、依赖、重复安装包和外部网页整页下载留在本机。事件中的实验输入、候选、退回、来源行和模型结果保留，便于复核行为。

0.7.2 分类重核对照的运行包采用确定性 gzip，原始证据完整保存于压缩内容。清单同时保存压缩包和解压后 JSON 的摘要，`verify.py` 核对两层摘要并重算用量。此前运行包的路径与字节保持不变。

`recordedUsage` 汇总所有已返回用量的模型响应。失败尝试单列，缺失用量保持未知。缓存输入包含在总 Token 中。单次对照结果与当时模型、提示、运行顺序和配置有关，实际费用以提供商账单为准。

0.7.0 的共同误判因素诊断和滚动阈值试验直接调用官方 API，保留真实请求、响应和原始用量；它们不冒充 DSH 原生闭环。阈值按每个会话实际累计缓存读取量判断，在持久化任务结果后交接，项目总量不清零。正确率、错误放行、正确样例误退与费用一起比较，未达到阈值的组不能用于证明交接效果。

```powershell
python experiments/verify.py
```

在原实验工作区重新导出时，指定原始工作区和输出目录。

```powershell
python experiments/archive.py <原始工作区> <公开数据目录>
```
