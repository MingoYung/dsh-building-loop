# 0.7.10 Windows 安装与正式桌面验收

受验源码提交为 `47b4d1cf03b521d4376b8910602c734dcf4048ce`，离线安装包 SHA-256 为 `7f7d831104bf52a686e773ed98cd97dc906c273d1d1b30b7332083f674feab59`。0.7.10 改变 Markdown 解析器的交付方式，保留原有解析依赖版本和规则。

| 场景 | 实测结果 |
|---|---|
| 0.7.9 从 GitHub 在线安装 | Windows DSH 发现页下载了指定提交，治理模块导入报 `ERR_MODULE_NOT_FOUND`。同版本 pnpm 的对照试验显示，声明自带依赖时会跳过解析安装，Git 下载包恰好缺这些依赖。删除声明的对照组可以解析依赖并导入。 |
| 0.7.10 从 GitHub 在线安装 | Windows DSH 内置 Discover 通过隔离配置中的测试索引显示卡片，再从 GitHub 在线下载指定提交。安装记录锁定 SHA 和下载完整性，4 个运行文件的摘要匹配，治理模块导入成功。图形界面立即启用后，宿主列表返回预设，新会话可以选用它。 |
| 0.7.10 离线安装及回退 | 用真实打包 Windows DSH NEXT 2.0.22-next 的内置 CLI 和 Electron Host 完成 8 项，覆盖原版、升级、回退和干净新装。升级与回退续用原子会话及账本标记，标准预设回归通过。 |
| 独立源码与解析等价 | 无 `node_modules` 的源码归档通过 260 项测试。独立离线重建的解析器和许可证逐字节匹配，256 份 Markdown 样本的语法树与原解析方式逐项一致。 |
| 正式桌面首次发送 | 直接启动后可进入正式 Profile，发送会话时内置聊天动效的 ASAR 图片流抛出 `ENOENT`。同一安装包的文件存在，默认临时目录中流式读取复现失败。原有修复启动快捷方式把 TEMP 和 TMP 改到专用目录后，两种受测资源流正常读取。 |
| 正式桌面修复启动后 | 在空验收工作区使用 DeepSeek V4.1 Flash。真实工具轨迹记录一次 `building_loop({action:"status"})`，返回 `{"role":"coordinator","units":[],"read":[],"write":[]}`。用时 4.24 秒，工具 11 毫秒，界面显示约 50K Token，缓存命中 7.99%。首次中断无用量记录。 |
