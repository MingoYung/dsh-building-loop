# 0.7.35 · 逐项交付与两道审核

上级为[实验与验收](README.md)。

0.7.34 的真实运行读取了有效原始记录和当前总纲，首审及独立复核也给出了有效的来源凭据。但最终候选把 E3 写为仍未决定是否待补，两道审核仍通过，宿主进入 `closed`。本轮冻结旧原稿、两份审核回执、资料和总纲摘要，在正常审核工具中验证有证据且缺结论、当前口径确实未定和有明确结果三条路线。 [原版本实验](results-0.7.34-assertion-proof.md)

| 冻结或派生样例 | 工具实际行为 |
|---|---|
| 冻结原稿引用齐全，只在条件中提及结果 | 拒绝拿条件中的词作为可执行的处置。该项如实标缺结果，回原执行会话补查 |
| 正文有结果，大白话写了不同结果 | 两处有不同的字段值，不能用其中一处取得两处通过 |
| 业务口径确实未定 | 宿主保存已定位的问题和目标版本，等待维护者澄清。原目标直接续跑会被拦，目标更新则转回原审核 |
| 明确处置且正文和大白话一致 | 两道审核分别保存三类证明，各项目的实际原始记录、按规则作处置、总结的一致性。宿主才允许进入账本复盘并关单 |

逐项范围来自当前总纲里的明确编号声明。证据齐备、逐项完成和总结一致是分别核对的三件事。简明处置字段有唯一的位置，解释性附文仍受全文核验。宿主核对字段、位置和原始证据，两位审核者需要独立判断结果是否合法。冻结回归还覆盖了跨章节借用、替换审核证明、重复声明和只有条件词的字段。真实模型按原项目业务提示走单一路径。

第一版候选的实际会话已完成 G1 的证据退回和 G2 目标交接。原执行方在 G2 给出了三项处置，送审却没有检查结果字段位置。首审发现字段不符合约定，反复尝试改工具引句，最终停在原审核会话。将该稿逐字冻结后，宿主在作者预检和送审都能一次报告三项字段问题，已到审核的旧稿则直接退回原执行方。

独立复现还发现，嵌套示例和摘要中的假设可以冒充正式结果，含连接号的业务编号会触发 Unicode 正则错误。样例现覆盖这三种写法。全量跑的中间版还发现了旧提示注入契约回归，已恢复该条款并保留失败记录。第一段真实稿的自动计分曾误把“排除，而不是待补”判成冲突。原评分保留，附有对应真实稿和正反对照。

精确候选包收录并核对 58 个宿主文件。旧结果和候选工具回放、真实宿主进度、审批与撤回的依据见[机器记录](observations-0.7.35-delivery-outcomes.json)。修改前的源文件和对应变更记录保存在同一滚动位置，正式桌面的回退包由原 Profile 单独管理。

## Windows DSH 真实验收

同一个 DeepSeek Flash 隔离会话贯穿 G1 事实退回、G2 目标更新和关单。续跑前保留原总控、执行方和首审的会话日志、当前稿及工作状态，换入最终候选后只发了一句通用继续消息。最终包 SHA-256 为 `7c3a66a79247541939b2c4ab5e2ab8690c79f799075bad2041938ea40d3d9337`。冻结回归 9/9、全量 Windows 回归 474/474。最终包在真实 Windows DSH 加载的 58 个文件均匹配；安装后零模型对照实际通过审核、复核及账本关单。

两道真实审核各覆盖 40 块、42 个片段，分别对 E1 纳入、E2 排除、E3 待补定位正文第 14–16 行和大白话第 39 行，绑定总纲第 4 行和演练登记第 3–5 行。每道回执分别保存 3 条原始事实、3 条正文处置及 3 条摘要处置证明。两位核验者也都独立区分了演练登记的资料身份与 GitHub 官方摘录。用保存的原始证明重算了两套哈希及对应的原文跨度。接受回执 SHA-256 为 `7c5107a271650a2e47842f883e42e57806be18e95f5b370adc790980aa2509a9`。

首审和独立复核都曾用未标类型的旧式证明提交，宿主分别拒绝，原审核者补齐本角色的证明后继续。独立复核也曾漏填总纲条款的空前提列表，随后自行修正。第一次独立复核发现 7 处证据分类分歧，只重核相关块，稿件字节保持一致，最终剩 0 处。原生账本复盘核对 8 项，预置事项的处理是动画失效、FAQ 已覆盖、暂停测验失效、未来链接复核保留，G2 的任务更新自动记账并标为完成。真实会话终态为 `closed`，19 项验收全部通过。

两段真实调用合计 218 次，共 13,185,233 Token，其中未命中输入 315,591、输出 123,274、缓存读取 12,746,368。缓存读取占输入的 97.58%。其中第一段 96 次、3,867,579 Token，停在首审，仍保留为失败证据。两段用量重算时按原生日志去重，未启动对比及 Token 优化。这是单一项目样例；真正待用户澄清的暂停和恢复已走冻结工具回归，本次真实 G2 的口径明确。
