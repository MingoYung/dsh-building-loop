# 本项目任务账本

上级为[项目总纲](../README.md)和[派单分块](work-delivery.md)。本文件管理插件自身的改进，不与每个使用项目的宿主运行账本混为一份。每轮实质变更完成时结合当前代码、验收报告和用户最新目标复盘。后续项不是无条件执行命令；开始前先核其必要性、影响和是否已被别的改动覆盖。

## 当前处理清单

2026-11-14 调整执行顺序。暂停标准模式、标准＋清单和 ClearAI 对比。优先用 Building-loop 自身的冻结样本、目标变更和实际宿主入口复现问题，核明是实现缺陷、条款缺失还是模型判断，并把成功和失败都留档。可复现的机制缺陷验收后，再优化 Token，并用原验收守住签名、独立复核和资料真实性。用量优化验收后只组织一次最终盲评，沿用短业务原文和隐藏用例，分别判断完成度及资料真实性。

0.7.8 保留为对照基线，R40、R41 的修复及原验收仍可回查。0.7.9 处理扩大的压力测试和真实运行中发现的边界，首对诊断和最终两组均有记录。[0.7.9 验收](../experiments/results-0.7.9.md) · [0.7.8 验收](../experiments/results-0.7.8.md)
